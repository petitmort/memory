# 潮汐之间 · Between the tides

一间建在悬崖边的圣托里尼书房，一本可以慢慢翻阅的回忆纪念册。白色石灰墙、淡青纱帘、复古木家具与少量古希腊神话收藏，围绕窗外的帆船和海景展开。书桌上放着木质黑胶唱片机，左侧配有燕麦色棉布豆袋沙发，以及一只带真实毛色和睡脸的狸花猫，让房间更像可以慢慢停留的家。

**在线体验：[潮汐之间](https://petitmort.github.io/memory/)** · 源码分支：`main` · 发布目录：`docs/`

项目使用 TypeScript + Three.js + Vite，纯静态运行，无后端，无需 API 密钥；默认素材随站点本地加载。

## 实时与自由时间流速

入室后点击「房间设置 → 时间 · 实时」打开时间设置。实时模式跟随设备日期与时间，保留桌面翻页时钟；选择「自由模式」后隐藏实体时钟，从当前时刻继续模拟昼夜和天气。滑动可选暂停、1、10、60、300、900、3600倍，也可输入0–3600之间的自定倍速，精度0.1；默认自由速度60倍，即现实1分钟经过模拟1小时。0倍只暂停日历、太阳 / 月亮和天气，海浪与房间仍自然活动；模拟时刻只在面板中显示，明确标为模拟时间。

改变流速不会跳到另一个日期，返回实时会平滑衔接当前光照 / 天气。船鸟、云移动、雨雪、雷声和灯塔保留自然动作速度，星空天文方向随日历变化，额外的24分钟展示转速保持原速。阅读或后台停止求值与渲染，返回直接恢复按经过时间计算的状态；不补播动画。

正常访客的模式、速度与自由时间锚点保存在当前浏览器，刷新后继续，存储不可用仍能使用。`debugEnv=1`始终使用独立临时设置，不读取或改写这份偏好；调试日期可重定自由时间起点，调试「恢复真实时间与自动环境」也会切回实时。设置面板在阅读 / 镜头移动 / 故障时收起，小屏内部滚动并保留房间按钮。支持1900–2100年范围，高速天气取样会压缩或合并部分短暂过程；船只始终按自然时间规划航次，模拟天气改变海面与帆面，不因快转或刷新重排船群。技术规则、实际测试与限制见[TIME-FLOW-PLAN.md](TIME-FLOW-PLAN.md)、[环境说明](ENVIRONMENT.md#实时与自由流速)及[性能记录](PERFORMANCE.md#2026-11-01--实时与自由时间流速)。

## 体验

- 淡青纱帘与蕾丝随当前模拟风速平滑改变摆幅：弱风轻动，强风更明显，静风逐渐停下；保留原有不规则波形、顶部固定与减少动态效果。

## 空间设计

- 远岛以绿色灌木和低矮树冠为主，深浅绿斑与实际冠层起伏对应，海水边只保留窄石岸；更远的岛屿降低对比并融入雾色。黄昏灯塔旋转时，光束范围内、朝向灯塔的岛坡会接收柔和暖光，并随扫光移过和淡出；岛屿保持真实的实体遮挡。[绿植岛屿与扫光记录](COAST-LIGHT-PLAN.md)保存本轮方案、验证与限制。
- 窗外是一条规整石砌码头，从右侧窗格右下方延伸至同一窗格中部较远处的白色灯塔，左侧保留连贯海景；塔身、阳台和屋顶均避开窗户中框。码头高出海面约1.85m，迎浪侧会随真实海浪抬起、外翻成破碎水花、落下飞沫并留下退沫；两侧强弱随风向和风速变化，平静时保留细小水花。太阳降至约8°时灯室开始渐亮，黄昏后形成柔和暖光；灯束按28秒一周连续缓慢旋转，暖白光芯与金色柔边形成可辨认的窄光柱，海面亮带方向一致；朝岸减弱并在室外边界渐隐，减少动态模式保留微弱静态向海光。[码头与拍浪逐步记录](PIER-SURF-PLAN.md)保存本轮验收。晴天、少云的深蓝夜空可见更细密的星场与不规则银河星云团：2K原创纹理包含分叉暗尘、细碎颗粒和克制冷暖层次，普通18,000 / 省电7,000星点向较亮星云密集分布，两者按场景纬度、朝向和日历时间缓慢转动；云、暮光与在地平线上方的月光会降低其可见程度。银河并非始终处于窗中央；普通模式星空与银河整体约24分钟转一周，数秒可察觉轻微位移，属于视觉时间压缩；这层展示转动不改变日月和天气流速，自由模式则按所选倍速推进日历。减少动态模式回到真实恒星时（约23小时56分一周）。[银河精细化记录](GALAXY-DETAIL-PLAN.md)、[历史实施记录](NIGHT-COAST-PLAN.md)与[环境技术说明](ENVIRONMENT.md)保留具体规则。

## 性能负载

- 海面网格由92,769降至40,337个顶点、79,872个三角形，使用16位索引；天气环境启用八方向风浪频谱，未接环境的独立海面仍保留原六组波浪，动态法线、反光与礁石破浪继续复用。泡沫只在可能出现的礁石周围计算，海面包围体涵盖波幅，支持视锥剔除。
- 纱帘预计算不随时间变化的褶皱和垂坠参数；动态顶点使用动态缓冲。翻页纸张只在弯曲进度变化时更新顶点，不为无光照纸张重复计算法线。
- 号角、锤子和三叉戟等收藏物在各自物件内部按材质合并，整组由 35 降至 11 个 Mesh，三角形、摆放边界和支撑位置不变。共享确定性的铜、木纹理，材质可独立调整。
- 开场五层雾带共用一张 256 × 256 密度纹理，通过实例化至多增加一次绘制、10 个三角形。雾的仿射坐标在顶点阶段计算，共享消散参数每帧计算一次；在采样前跳过保证透明的区域，并只移除当前视野内已完全透明的雾层，可见雾的纹理、浓度和流动保持原样。雾带不投影、不参与拾取，也不使用全屏模糊或额外离屏渲染；散尽后整组隐藏，室内不继续绘制。
- 庭院静止时以约每秒 30 次的频率绘制，入室和阅读视角过渡使用正常帧调度。阅读与后台停留不持续调度渲染；画质降低时不会把像素比从更低的自适应值重新提高到 1。

唱片机共 9 个 Mesh、4,476 个三角形，几何缓冲约 398 KiB，使用小型原创木纹、唱片纹理和环向反光贴图，并参与入室前的预编译和预热。播放时唱片按 33⅓ RPM 转动，唱臂随播放状态落下或抬起；唱臂稳定后，圆形唱盘的转动继续复用静态阴影。减少动态效果模式下保留播放状态，停止唱盘转动。音乐由单个原生 HTMLAudioElement 播放，使用 `preload="none"`，不新建 AudioContext，也不在点击时预先解码整首歌曲。海浪增益从原来的 0.16 调为 0.065，音乐播放时降至 0.032，以 1.2 秒时间常数平滑变化。

## 换成自己的回忆

可使用上方[可视化工作台](#纪念手帐可视化编辑)自行创作并导出内容包，[使用说明](ALBUM-EDITOR-GUIDE.md)介绍完整流程。以下保留原`content.ts`四章的手动维护方式；没有自定义成稿时网站继续使用它，内容包不会自动发布。

编辑 `src/content.ts` 中的 `chapters` 数组：

- `title`：章节标题，`date`：章节编号与名称，`subtitle`：英文小标题。
- `text`：短句，`note`：正文。字符串内的 `\n` 表示换行。
- `caption`：图下注释。
- `scene`：内置插画主题，支持 `coast`、`sunset`、`mountain`、`night`。
- 可选 `image`：照片路径。例如把照片放入 `public/memories/first.webp`，填写 `image: 'memories/first.webp'`。该相对路径同时适用于本地预览和 GitHub Pages 的 `/memory/` 子路径；加载失败时回退到插画。

照片路径直接交给浏览器解析，不会自动添加站点前缀，因此上述本地照片路径不要以 `/` 开头。建议使用宽度约 1200 像素的 WebP；照片默认按画框裁切。章节和页码按数组长度自动生成。修改内容或素材后，需要重新构建并发布。

## 上传自己的音乐

默认唱片为用户提供的《Merry Christmas Mr. Lawrence》— 坂本龍一，随网站提供给访客。庭院阶段保持暂停；推门入室的原生点击 / 键盘手势会自动启动当前唱片，默认音频也在此时才开始加载。可点击唱片机暂停，只听海浪；浏览器若拒绝播放，可轻触唱片机重试。选过个人音乐后，唱片机说明中的“恢复默认唱片”可清除个人曲目的保存记录并换回默认音乐。

点击“更换音乐”可选择设备上的其他音频。唱片机显示加载中、播放中、已暂停和失败状态，并显示默认曲目名称或所选文件名；点击唱片机可暂停或从原进度继续。最近选择的一首个人音乐及其文件名通过 IndexedDB 保存在当前设备的当前浏览器中；刷新或再次打开时优先读取这首音乐，在下一次推门入室时自动启动；在庭院或纪念册故障入口不自行播放。个人选择的文件不上传到服务器，也不会成为网站的公共音乐，其他设备或浏览器不会自动同步。

清除网站数据会删除保存的个人音乐，再次打开时恢复默认唱片。无痕浏览、浏览器存储限制或空间不足也可能影响保存；无法读取已保存歌曲时使用默认唱片。保存失败时会提示，本次仍可播放所选文件。支持的音频格式由浏览器决定，建议使用 MP3 或 M4A；更多操作说明见 [音乐说明](public/music/README.md)。
