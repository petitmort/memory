# 潮汐之间 · Between the tides

一间建在悬崖边的圣托里尼书房，一本可以慢慢翻阅的回忆纪念册。白色石灰墙、淡青纱帘、复古木家具与少量古希腊神话收藏，围绕窗外的帆船和海景展开。书桌上放着木质黑胶唱片机，左侧配有暖赭黄色棉布豆袋沙发，以及一只带真实毛色和睡脸的狸花猫，让房间更像可以慢慢停留的家。

**在线体验：[潮汐之间](https://petitmort.github.io/memory/)** · 源码分支：`main` · 发布目录：`docs/`

项目使用 TypeScript + Three.js + Vite，纯静态运行，无后端，无需 API 密钥；默认素材随站点本地加载。

## 开发

需要 Node.js 22.12+；作者Mac复用24.14.0，云端以实际Node版本为准。在项目目录执行：

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

安装使用 `package-lock.json`。在用户目录不可写的云环境，可改用 `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`。

在作者的 Mac 上复用共享 Node `~/.nvm/versions/node/v24.14.0`（入口 `~/.local/bin/project-node`）、项目现有 `node_modules` 和共享包仓库 `~/Library/pnpm/store/v11`，无需为本项目另装 Node 或复制依赖环境。可直接运行 `~/.local/bin/project-node node_modules/typescript/bin/tsc --noEmit`、`~/.local/bin/project-node node_modules/vite/bin/vite.js build`、`~/.local/bin/project-node node_modules/@playwright/test/cli.js test`（先运行现有开发服务器）；Playwright默认兼容Mac Chrome / Linux Chromium，支持 `CHROMIUM_PATH` 覆盖。离线猫咪骨骼烘焙命令为 `~/.local/bin/project-node scripts/rig-sleeping-cat.mjs`。

检查、构建与预览：

```sh
npm run typecheck
npm run build
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

`npm run build` 会先执行 TypeScript 检查，再输出到 `dist/`。生产资源使用相对路径，支持 GitHub Pages 的 `/memory/` 子路径；请通过开发服务器或预览服务器访问，不要直接双击 HTML 文件。

## GitHub Pages 发布

当前站点通过 GitHub Pages 从 `main` 分支的 `/docs` 目录发布。首次配置时，在仓库 Settings → Pages 中，将 Source 设为 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/docs**。

更新源码后，重新构建、清理旧哈希资源，再提交源码与发布文件：

```sh
npm run build
rm -rf docs/assets
cp -R dist/. docs/
touch docs/.nojekyll
git add AGENTS.md README.md src public tests index.html package.json package-lock.json vite.config.ts playwright.config.ts docs
git commit -m "Update published site"
git push origin main
```

推送后等待 Pages 部署完成。若仍看到旧画面，可使用带版本参数的链接，例如 `https://petitmort.github.io/memory/?v=本次提交号`，并确认页面引用的是新构建的资源。也可以将完整 `dist/` 发布到其他静态托管服务。

## 体验

- 开场位于围合入口庭院，浓雾中透出蓝色拱门、灯笼和植栽的轮廓；雾散后显露铜制玻璃灯笼、手绘门牌、长椅织物与成簇植栽，进入房间后才揭示窗外海景。门前不提交被建筑完全遮挡的海景、花束和画册等细节，推门前恢复可见性，保留穿门过程中的自然揭示。
- 第一次点击驱散雾气，第二次点击开门。开场使用五层有远近遮挡的流动雾带与真实距离雾，近层先散、靠门的远层稍后散开，门前雾窗和外围雾丝交叠变化；保留同一站位和普通模式约 1.85 秒的总时长。清雾按实际绘制帧推进，完整绘制清晰庭院后才解锁开门；切到后台时暂停进度，减少动态效果模式会缩短清雾并放慢雾带流动。
- 门先转动并实际绘制至让出通道后，镜头才开始前进。入室镜头保持 1.65 米人眼高度和原有门洞路线，按路程采样并柔和起步、停稳，普通模式约 3.8 秒，不穿墙，也不隐藏墙面。后台暂停门与行走进度；移动中跨手机布局断点时，先安全通过门框，再保持速度接向新机位。海浪声入室后淡入，右上角可随时静音。
- 散雾完成后按钮明确变为“推开这扇门”，并给出一次柔和的就绪反馈。首次入室镜头停稳后，先保留约 2 秒可见观赏时间，再用约 450 ms 淡入主要操作；减少动态模式直接显示。从停稳起累计约 6 秒可见时间仍未操作时，才显示一次探索说明，约 4 秒后消失。后台暂停剩余等待，首次点击、触摸按下或键盘操作立即取消自动说明，本次访问不补发；单纯鼠标移动不算主动操作，悬停物件反馈优先，不与说明叠加。沿用已看说明的浏览器记录，存储不可用时仍保证本次访问最多一次。观赏期主动操作立即响应，按住手势时不会突然在指针下插入按钮；返回房间不重复等待或补发说明。
- 花束、画册、小猫和唱片机保留鼠标悬停及触摸按下反馈，首次受理可显示说明；同一物件再次悬停只显示名称，重复按下和受理使用轻微圆点反馈，继续保留物件动作、声音和必要的加载 / 失败 / 过渡状态。猫咪首次回应可解释动作，之后只提示简短的忙碌或就绪状态，不改变动作和音频。悬停、按下、松开及猫咪轻划统一选择最近且可见的命中对象，家具遮挡继续有效；普通拖动约 10 px、多指、后台、缩放、禁用交互及场景失效会取消旧手势并释放捕获，恢复后松手不补触发。视角、开合书和切章进行中继续锁定相关重复命令，不增加自动物件强调或持续闪烁的标记。
- 唱片机默认放入用户提供的《Merry Christmas Mr. Lawrence》— 坂本龍一。入室后点击桌上的唱片机或右上角唱片按钮开始播放，也可暂停或从原进度继续；不会自动播放。可使用“更换音乐”选择设备上的其他歌曲，最近选择的一首个人音乐保存在当前浏览器中，不上传到服务器；下次打开时优先读取这首音乐，没有保存歌曲或无法读取浏览器存储时使用默认唱片。
- 音乐可以伴随纪念册阅读；切到后台时暂停，返回页面后由用户继续播放。全局静音同时控制音乐、海浪和猫咪声音，音乐保持播放进度。海浪底音已调轻，音乐播放时进一步降低，并平滑变化，给旋律留出空间。也可以不播放唱片，只听海浪；使用方式见[上传自己的音乐](#上传自己的音乐)。
- 点击花束或按钮，花束轻轻挪到桌面右侧并留在那里，保持尺寸和可见性。随后镜头连续靠近并俯视书本，封面沿书脊打开，一张纸页弯曲翻过。镜头与左右阅读页由同一个逐帧进度驱动，阅读页在镜头仍然移动时接续展开，直到阅读位置稳定。
- 书本上的文字、插画或照片直接取自实际阅读页面的栅格图，保留相同排版与裁图；实体与阅读纸页重叠时保持相同位置，交接后再展开，手机上左右两页分别移向纵向阅读位置。暗角先随镜头淡出，装订阴影等纸页接近终位再显现，避免提前出现另一块大纸底板。
- 关闭纪念册时，从当前阅读机位开始连续收回桌面书本，纸页与封面合拢，最后回到入室后的房间视角；当前章节与桌旁的花束都会保留。阅读停留时间不会计入返回首帧。开册和返回期间锁定重复操作，页面稳定后才恢复阅读控件；窗口调整保持运动速度，跨手机布局断点时平滑重定向。
- 返回房间后，点击桌上的画册或“继续翻阅纪念册”按钮，从当前章节继续阅读；花束留在桌旁。
- WebGL 失败时保留纪念册阅读入口；“重新载入房间”会携带当前章节执行一次重试，即使仍无法显示房间也能接着阅读。普通刷新或重新进入仍从第一章开始。
- 入室后可点击“看看睡着的小猫”，沿家具前方的空地平滑靠近休息角，保持 1.65 米站立人眼高度，并调整取景，让小猫的毛色、睡脸和布料细节更清楚；再点“看回书桌”平滑退回原机位。靠近和返回期间锁定重复操作，路径避开书桌、凳子、沙发和墙面；手机优先完整展示小猫，外侧沙发可自然裁切。看猫时收起纪念册按钮和阅读提示，先点“看回书桌”，镜头返回完成后才恢复阅读入口；靠近与返回途中也不显示纪念册入口。看猫期间调整窗口不会退回远景，跨布局断点时正在进行的移动会从当前位置和速度继续。
- 点击、轻触或在小猫身上轻划即可抚摸；在书桌前点到实际可见的小猫，会先沿现有路线靠近休息角，镜头停稳后才开始动作和声音。近看时点击小猫直接回应，也可用“抚摸小猫”按钮和键盘操作。小猫会沿连续的弧线轻轻抬头转头，肩颈先舒展，头部接着轻蹭，耳朵随头部运动并独立轻摆，分节尾巴稍后跟随；每次从满足、好奇、亲昵、困倦、轻快与伸展六组反应中随机选择，避免连续重复，并小幅改变转头方向、幅度和尾巴相位；对应叫声与抬头、摆耳共用时间轴，叫完再慢慢蜷回去，脚底、后腿和尾根保持承托。整段反应约 4.4 秒；减少动态效果模式保留同样节奏，只降低幅度。只接收落在实际可见猫咪上的单指或鼠标主键操作，划动约 10 px 后触发一次；多指、取消手势和移动或动作中的重复输入不会排队，也不会因划到书桌上而误开画册。靠近途中切到后台会取消待播放的抚摸，返回页面后只完成镜头移动，不补播反应；画面失效或离开页面也会取消。
- 开启声音后，每次抚摸选择一组成对的动作与声音：自然呼噜配单声、双声或快慢不同的短喵叫，六组声音使用 Joseph Sardin / BigSoundBank 的两段 CC0 猫叫录音编排，轻微调整速度、音高和音量。满足、好奇等名称描述互动风格，不判断真实动物的情绪。每组是一段合并音轨，动作读取这次播放捕获的音频时钟，并对齐叫声起点、重音与结束；不分别随机挑声音和动作。静音时保持相同动作节奏，切后台、进入阅读、设备中断或离开页面会取消整段声音，尚未响起的第二声也一起取消，返回后不补播。声音未就绪时本次仅播放动作，不插入迟到的叫声；六组录音在加载期独立准备，共用原有音频设备。来源及处理见[声音说明](public/audio/README.md)，作者与许可也可从“猫咪素材鸣谢”查看。
- 花束使用独立卷边花瓣、错落的花心与玫瑰红配色，通过四组实例批量绘制花瓣。
- 海面使用细分网格与不同方向、频率和速度的波浪，实际改变表面高度；光照法线随波面变化。反光跟随实际太阳方向，结合天空映照和随视角变化的水面光泽，并过滤远处无法分辨的细波，减少点阵状闪烁。减少动态效果模式下海浪放慢。
- 桌面使用上一章、下一章、方向键和章节圆点切换章节；翻页是切章时的纸页动画，操作含义保持一致。可展开“章节目录”直接跳转；Escape 先收起目录，再返回房间。手机只将明确的单指横向滑动识别为切章，斜向或纵向滚动、双指及取消手势不会误翻。正文为至少 16px、图片说明为至少 14px，窄屏按单列纵向阅读，短横屏保留可滚动正文与固定操作栏。
- 桌面向后翻阅时，正在转动的纸页正面保留当前右页；越过 90° 后，背面显示下一章左页的插画或照片，新的右页从纸张下方露出，纸页落定后才更新当前章节。反向翻阅按相反顺序显示，文字和图片不镜像。照片在翻页前准备，解码失败或等待超过 1.2 秒时使用本地插画，并保留到本章结束；再次切回该章可重试照片。窗口缩放会取消本次翻页并恢复操作，手机单列和减少动态效果模式继续使用淡变。
- 房间控件共享暖纸白与深海绿、边框、圆角及柔和阴影，主操作与次要操作保持层级；房间提示与纪念册按钮放在同一个操作区中，按内容自然排布；音乐曲名过长时省略，播放与静音状态保留完整。操作区与底部画质控件至少留出约 12 px 间距，并随手机横竖屏和安全区调整。手机按钮采用紧凑布局，为画册与花束的点击区域留出空间；右上角可切换声音、进入全屏，底部可切换自适应画质与省电档。
- 在房间或纪念册入口，点击左上角名称可重新开始体验。阅读期间背景控件退出键盘导航，切章后保留焦点；支持阅读焦点限制和 Escape 返回。
- 遵循系统的减少动态效果偏好：缩短入室、移花和阅读视角过渡，减慢海浪和纱帘等风动，并将阅读界面的立体翻页改为短暂淡变。
- 首次交互前预编译材质，并在加载遮罩下以 16 × 16 物理像素预热模型、原尺寸纹理和完整阴影着色器，保持正式画面的像素比、材质与阴影分辨率；画质自适应限制最高像素比，持续低帧率时降低分辨率，另有省电档。海浪音频设备在加载期静音、暂停准备，八秒音轨按小批次生成，首次点击只解锁已准备的上下文；未交互时切回页面不会自动播放。日历方向光每约15秒更新阴影，门、花束、画册或小猫等投影物变化时也重绘；镜头移动可复用已有阴影。阅读期间暂停背景绘制，返回房间再继续。
- 阅读停留或页面在后台时取消渲染帧回调，按需重绘窗口调整后的背景；返回房间、切回页面后再唤醒。海浪、纱帘和行走的计时排除暂停时间；天体、天气、云与船按当前绝对日历时间恢复，不从起点集中重播。页面在后台暂停音频。WebGL 不可用或运行中断时自动转为可用的纪念册阅读，保留当前章节；入室、开合及纸页捕获中的等待会随中断结束，晚到的素材不会重新启动失效场景。返回纪念册入口后可选择重新载入房间。

当前包含四章示例文案和程序生成的原创插画，可替换为自己的文字与照片。重新打开未修改的章节会复用现有内容；配置照片时，加载失败或桌面翻页前解码等待超时会生成备用插画。照片供实体书栅格化时按实际画框和最高 1.5 倍像素比降采样，避免再次编码完整相机原图。

## 空间设计

- 建筑以白色石灰抹墙、真实弧形门洞与钴蓝木门为主，保留 90 × 210 cm 的门扇外包络尺寸。地面采用暖米色石灰岩与约 60 cm 的方形铺砖分缝。
- 窗边配半透明淡青色纱帘和蕾丝边。布料褶皱、垂坠与边缘随小幅风起和平息变化，两片纱帘错开节奏，蕾丝跟随同一片布料运动；减少动态效果模式同时降低风动速度和幅度。窗侧设有做旧蓝色百叶木窗。
- 室内保留清透日光，以略冷的天光、柔和暖白直射与补光拉开墙面、橡木、棉布和透明盖的层次；细调曝光、粗糙度及反光，不新增灯光或阴影通道。书桌左侧的豆袋沙发以靠背朝向左墙，向室内略展开约 9°，最近离墙约 7 cm，并放在边桌前方留出间距，不占入门行走路线。造型按参考图保留宽厚方底、略窄且后倾的矩形靠背，以及从后向前降低的软扶手；柔化集中在转角、布套鼓起和局部塌陷处。低座面与上靠背、腰部填充分区清楚，靠背上下两段由同一片布面的鼓起、浅折痕和细缝线形成。轮廓顶点均匀分布，减少转角处的长直线段；布片交界共享平滑法线、保留各自的实际织纹尺度。暖赭黄色棉布使用原创摄影风格织物贴图，配独立细纱法线、粗糙度和柔和纤维反光；织纹按约 12 cm 一块的实际尺度平铺。造型参考用户提供的豆袋椅照片，并非品牌官方模型。
- 狸花猫采用 Alben Tan 的 CC BY 4.0 真实扫描，保留闭眼睡脸、耳朵轮廓和摄影毛色，替换原来的几何拼接模型。模型已去除原桌面，收起后腿、把头向内放低，并让尾巴贴合外侧轮廓，形成约 43 × 32 × 11 cm 的紧凑蜷睡姿势，卧在软垫上。固定支撑面的轻微呼吸继续保留；抚摸使用 GLB 内的局部骨骼与六组实时动作曲线，头颈连续转动，耳朵随头部运动，四节尾骨形成滞后的轻扫，结束后精确恢复睡姿。尾巴按独立连通表面蒙皮，避免连同下面的后腿一起变形。网上检索的开放许可模型仅用于结构参考，未导入其模型、动画或图片；当前外观仍来自原扫描，动作由本项目制作。减少动态效果模式会降低幅度，阅读或切到后台时暂停持续绘制。查看小猫时可打开“猫咪素材鸣谢”阅读模型、声音的作者、许可与修改说明。
- 室内使用复古橡木桌面、车木桌腿、亚麻坐垫和黄铜细节。左墙画作与窄边桌对齐，只保留一件青铜器皿和浅托盘，窗景与阅读桌之间留出空间。
- 黑胶唱片机参考用户提供的木质机型照片，采用约 40 × 34 cm 的胡桃木底座、直径 30 cm 的唱片、银黑色唱臂和抬起约 55° 的茶色透明防尘盖，打开后总高约 40 cm。机器置于书桌后侧偏右，杯子移至左前侧、信笺后移；花束移开后横放在右前侧，与唱片机和打开的画册错开，底座与支脚完整落在桌面上。
- 藤编篮完整摆放在入口长椅旁，衬布折放在篮口内；号角与锤子安放在入口壁架上，三叉戟靠近入口内侧墙面。家具与物件保持日常尺寸，门洞和行走路线不堆放装饰。
- 庭院以层叠石灰门套、铜制玻璃灯笼、手绘陶瓷门牌、陶土与陶瓷花盆补充墙面层次。长椅配软坐垫、靠垫和垂下的条纹亚麻织物；橄榄树与三角梅使用相连枝干和成簇叶花，保留门洞与行走空间。远处点缀小型海边村落。
- 木帆船包含内外船壳、木板缝、肋骨、甲板、船桨、尾舵与索具。方帆沿船身横向桁杆展开，带亚麻纹理、缝线、鼓起与细褶；船身随同一套海浪起伏。船位兼顾桌面与手机窄屏视野。
- 海上有两座低矮、不对称的远岛、两组基部沉水的断岩礁石和少量滑翔海鸟。礁石带湿暗潮线与分层裂面，周围破浪泡沫随海面变化；船与礁石保持间距。
- 太阳保留明亮圆盘，外围光晕收敛；远岛带低对比的蓝灰空气感，远浪高光更克制，保留近窗框、中景船海和远岛的层次。当前海景已移除太阳浮雕、海怪和漩涡，保留自然海岸的开阔感。

墙面、石材、帘布及陶瓷图案使用本地程序素材；画作、橡木纹理和豆袋棉布由项目生成图片制作，随站点本地加载。素材说明见 [画作来源](public/art/README.md)、[橡木纹理来源](public/materials/README.md)、[豆袋棉布来源](public/materials/beanbag-cotton.README.md) 与 [狸花猫模型来源及许可](public/models/README.md)。百叶、叶片等重复物件采用批量绘制，帆船小部件按材质合并，以控制场景开销。

## 性能负载

- 海面网格由 92,769 降至 40,337 个顶点、79,872 个三角形，使用 16 位索引；全部六组波浪、动态法线、反光与礁石破浪仍保留。泡沫只在可能出现的礁石周围计算，海面包围体涵盖波幅，支持视锥剔除。
- 纱帘预计算不随时间变化的褶皱和垂坠参数；动态顶点使用动态缓冲。翻页纸张只在弯曲进度变化时更新顶点，不为无光照纸张重复计算法线。
- 号角、锤子和三叉戟等收藏物在各自物件内部按材质合并，整组由 35 降至 11 个 Mesh，三角形、摆放边界和支撑位置不变。共享确定性的铜、木纹理，材质可独立调整。
- 开场五层雾带共用一张 256 × 256 密度纹理，通过实例化至多增加一次绘制、10 个三角形。雾的仿射坐标在顶点阶段计算，共享消散参数每帧计算一次；在采样前跳过保证透明的区域，并只移除当前视野内已完全透明的雾层，可见雾的纹理、浓度和流动保持原样。雾带不投影、不参与拾取，也不使用全屏模糊或额外离屏渲染；散尽后整组隐藏，室内不继续绘制。
- 庭院静止时以约每秒 30 次的频率绘制，入室和阅读视角过渡使用正常帧调度。阅读与后台停留不持续调度渲染；画质降低时不会把像素比从更低的自适应值重新提高到 1。

本轮以 `ae381e3` 为基线，在同一 960 × 640、像素比 1、Chromium / SwiftShader 环境记录点击阶段：首次音频同步准备约 60 ms 降到 1 ms 以内；首次入室帧的主线程 P95 由约 118 ms 降到约 6 ms，该阶段新增的 250 次静态几何缓冲上传及 4 次着色器编译均移到加载期。固定时间和消散阶段的八组雾画面对比，最大每色道误差为 1/255；这是浮点插值造成的色阶差异。独立雾层绘制在消散后半段的 GPU 完成及读回时间下降约 56%–81%，此数据用于同环境比较，不代表真实手机帧率。

当前沙发、座面和缝线共 15,680 个三角形、3 个 Mesh；加上狸花猫，休息角共 35,887 个三角形、4 个 Mesh。棉布颜色、法线和粗糙度贴图分别为 1024、512、256 像素，合计约 447 KiB，壳体与座面共享贴图，不在运行中生成织纹。扫描猫使用一个网格和一张内嵌的 1024 × 1024 JPEG；本地 GLB 约 1,103 KiB（1,129,876 字节），通过 Vite 按内容生成文件名，更新姿势后会加载对应的新模型；不加载原始高分辨率纹理，也不模拟逐根毛发。首次预热会等待猫模型和棉布贴图就绪，再预编译、上传资源，避免把加载工作留到点击之后；素材请求或解码期间画面失效，会取消等待并保留可用的阅读入口，晚到的结果不会复活场景，已创建的棉布材质和贴图也会释放。门前隐藏休息角，阅读或后台继续使用暂停调度。

抚摸保留 GLB 内的 10 根局部骨骼、蒙皮和原有三段 4.4 秒离线动画数据，源模型不重新烘焙。实时回应改为从六组连续骨骼曲线中随机选择，用同一个反应对象绑定声音、姿态、叫声起止与重音；每轮六组打乱顺序，跨轮也避免连续重复，转向、幅度和尾巴相位带轻微变化。骨骼仍驱动现有网格，不增加三角形、材质、纹理或每次交互的几何上传。原有三段 GLB 动画及烘焙脚本保留，用于兼容和可重复验证；它们不再是实时回应唯一的动作来源。

肩颈先舒展、头部连续轻蹭，耳朵与分节尾巴错开跟随；脚底、后腿和尾根保持承托。每组动作在对应叫声前抬头，在声音期间保持回应，再安静恢复睡姿；减少动态模式按 0.16 缩小幅度，结束和取消都精确复位。六组小音轨合计 177,637 字节，单声道解码缓冲合计 3,060,792 字节，独立于场景就绪准备，不新建 AudioContext，也不在点击时解码或合成声音。有声音时动作读取该次播放的时钟，静音时按首个绘制帧起的场景时间推进；慢帧不会独立拖长其中一方。动画包围体、材质、扫描模型和原始贴图复用既有资源。声音编排与素材说明见[声音来源](public/audio/README.md)，模型与原有离线动画说明见[模型说明](public/models/README.md)。

唱片机共 9 个 Mesh、4,476 个三角形，几何缓冲约 398 KiB，使用小型原创木纹、唱片纹理和环向反光贴图，并参与入室前的预编译和预热。播放时唱片按 33⅓ RPM 转动，唱臂随播放状态落下或抬起；唱臂稳定后，圆形唱盘的转动继续复用静态阴影。减少动态效果模式下保留播放状态，停止唱盘转动。音乐由单个原生 HTMLAudioElement 播放，使用 `preload="none"`，不新建 AudioContext，也不在点击时预先解码整首歌曲。海浪增益从原来的 0.16 调为 0.065，音乐播放时降至 0.032，以 1.2 秒时间常数平滑变化。

性能优化版的唯一几何体属性及索引缓冲合计约由 13.6 MB 降至 10.2 MB（-25%）。上述指标衡量提交工作量与几何缓冲，使用云端 Chromium / SwiftShader 采集，不等同于整页内存占用或真实手机帧率。

## 换成自己的回忆

编辑 `src/content.ts` 中的 `chapters` 数组：

- `title`：章节标题，`date`：章节编号与名称，`subtitle`：英文小标题。
- `text`：短句，`note`：正文。字符串内的 `\n` 表示换行。
- `caption`：图下注释。
- `scene`：内置插画主题，支持 `coast`、`sunset`、`mountain`、`night`。
- 可选 `image`：照片路径。例如把照片放入 `public/memories/first.webp`，填写 `image: 'memories/first.webp'`。该相对路径同时适用于本地预览和 GitHub Pages 的 `/memory/` 子路径；加载失败时回退到插画。

照片路径直接交给浏览器解析，不会自动添加站点前缀，因此上述本地照片路径不要以 `/` 开头。建议使用宽度约 1200 像素的 WebP；照片默认按画框裁切。章节和页码按数组长度自动生成。修改内容或素材后，需要重新构建并发布。

## 上传自己的音乐

默认唱片为用户提供的《Merry Christmas Mr. Lawrence》— 坂本龍一，随网站提供给访客。初始保持暂停，首次点击播放时才加载这份音频；入室后点击桌上的唱片机或右上角唱片按钮开始播放，也可以只听海浪。选过个人音乐后，唱片机说明中的“恢复默认唱片”可清除个人曲目的保存记录并换回默认音乐。

点击“更换音乐”可选择设备上的其他音频。唱片机显示加载中、播放中、已暂停和失败状态，并显示默认曲目名称或所选文件名；点击唱片机可暂停或从原进度继续。最近选择的一首个人音乐及其文件名通过 IndexedDB 保存在当前设备的当前浏览器中；刷新或再次打开时优先读取这首音乐，保持暂停，点击唱片机再开始播放。个人选择的文件不上传到服务器，也不会成为网站的公共音乐，其他设备或浏览器不会自动同步。

清除网站数据会删除保存的个人音乐，再次打开时恢复默认唱片。无痕浏览、浏览器存储限制或空间不足也可能影响保存；无法读取已保存歌曲时使用默认唱片。保存失败时会提示，本次仍可播放所选文件。支持的音频格式由浏览器决定，建议使用 MP3 或 M4A；更多操作说明见 [音乐说明](public/music/README.md)。
