# 潮汐之间 · Between the tides

一间建在悬崖边的圣托里尼书房，一本可以慢慢翻阅的回忆纪念册。白色石灰墙、淡青纱帘、复古木家具与少量古希腊神话收藏，共同围绕窗外的帆船和海景展开。

**在线体验：[潮汐之间](https://petitmort.github.io/memory/)** · 源码分支：`main` · 发布目录：`docs/`

项目使用 TypeScript + Three.js + Vite，纯静态运行，无后端，无需 API 密钥；默认素材随站点本地加载。

## 开发

需要 Node.js 22.12+（本云环境为 24.19.0）。在项目目录执行：

```sh
npm ci
npm run dev -- --host 0.0.0.0 --port 5173 --strictPort
```

安装使用 `package-lock.json`。在用户目录不可写的云环境，可改用 `npm ci --cache /workspace/.npm-cache --no-audit --no-fund`。

检查、构建与预览：

```sh
npm run typecheck
npm run build
npm run preview -- --host 0.0.0.0 --port 4173 --strictPort
```

`npm run build` 会先执行 TypeScript 检查，再输出到 `dist/`。生产资源使用相对路径，支持 GitHub Pages 的 `/memory/` 子路径；请通过开发服务器或预览服务器访问，不要直接双击 HTML 文件。

## GitHub Pages 发布

当前站点通过 GitHub Pages 从 `main` 分支的 `/docs` 目录发布。首次配置时，在仓库 Settings → Pages 中，将 Source 设为 **Deploy from a branch**，Branch 选择 **main**，目录选择 **/docs**。

更新源码后，重新构建、清理旧哈希资源，再提交源码与发布文件：

```sh
npm run build
rm -rf docs/assets
cp -R dist/. docs/
touch docs/.nojekyll
git add README.md src public index.html package.json package-lock.json vite.config.ts docs
git commit -m "Update published site"
git push origin main
```

推送后等待 Pages 部署完成。若仍看到旧画面，可使用带版本参数的链接，例如 `https://petitmort.github.io/memory/?v=本次提交号`，并确认页面引用的是新构建的资源。也可以将完整 `dist/` 发布到其他静态托管服务。

## 体验

- 开场位于围合入口庭院，先看到蓝色拱门、铜制玻璃灯笼、手绘门牌、长椅织物与成簇植栽；进入房间后才揭示窗外海景。
- 第一次点击驱散雾气，第二次点击开门。过渡期间锁定操作，防止误触。
- 入室镜头保持 1.65 米人眼高度，从真实门洞进入房间后停下，不穿墙，也不隐藏墙面。海浪声入室后淡入，右上角可随时静音。
- 点击花束或按钮，花束轻轻挪到桌面右侧并留在那里，保持尺寸和可见性。随后镜头连续靠近并俯视书本，封面沿书脊打开，一张纸页弯曲翻过。镜头与左右阅读页由同一个逐帧进度驱动，阅读页在镜头仍然移动时接续展开，直到阅读位置稳定。
- 书本上的文字、插画或照片直接取自实际阅读页面的栅格图，保留相同排版与裁图；手机上左右两页分别移向纵向阅读位置。阅读背景遮罩与模糊度平滑抵达各屏幕尺寸的最终样式。
- 关闭纪念册时，阅读页面随着镜头移动收回桌面书本，纸页与封面合拢，最后回到入室后的房间视角；当前章节与桌旁的花束都会保留。开册和返回期间锁定重复操作，页面稳定后才恢复阅读控件。
- 返回房间后，点击桌上的画册或“继续翻阅纪念册”按钮，从当前章节继续阅读；花束留在桌旁。
- 花束使用独立卷边花瓣、错落的花心与玫瑰红配色，通过四组实例批量绘制花瓣。
- 海面使用细分网格与不同方向、频率和速度的波浪，实际改变表面高度；光照法线随波面变化。反光跟随实际太阳方向，结合天空映照和随视角变化的水面光泽，并过滤远处无法分辨的细波，减少点阵状闪烁。减少动态效果模式下海浪放慢。
- 桌面使用左右按钮、方向键、章节圆点翻页；手机支持左右滑动与纵向阅读。
- 手机按钮采用紧凑布局，为桌面画册与花束的点击区域留出空间。右上角可切换声音、进入全屏，底部可切换自适应画质与省电档。
- 阅读或在房间内时，点击左上角名称可重新开始体验。支持键盘焦点、阅读焦点限制和 Escape 返回。
- 遵循系统的减少动态效果偏好：缩短入室、移花和阅读视角过渡，减慢海浪和纱帘等风动，并将阅读界面的立体翻页改为短暂淡变。
- 首次交互前预编译材质与预热场景；画质自适应限制最高像素比，持续低帧率时降低分辨率，另有省电档。阅读期间暂停背景绘制，返回房间再继续。
- 页面在后台停止绘制、暂停音频。WebGL 不可用时可直接阅读纪念册。

当前包含四章示例文案和程序生成的原创插画，可替换为自己的文字与照片。

## 空间设计

- 建筑以白色石灰抹墙、真实弧形门洞与钴蓝木门为主，保留 90 × 210 cm 的门扇外包络尺寸。地面采用暖米色石灰岩与约 60 cm 的方形铺砖分缝。
- 窗边配半透明淡青色纱帘和蕾丝边。布料褶皱、垂坠与边缘随风起伏，蕾丝跟随同一片布料运动；减少动态效果模式会放缓风动。窗侧设有做旧蓝色百叶木窗。
- 室内使用复古橡木桌面、车木桌腿、亚麻坐垫和黄铜细节。左墙画作与窄边桌对齐，只保留一件青铜器皿和浅托盘，窗景与阅读桌之间留出空间。
- 藤编篮完整摆放在入口长椅旁，衬布折放在篮口内；号角与锤子安放在入口壁架上，三叉戟靠近入口内侧墙面。家具与物件保持日常尺寸，门洞和行走路线不堆放装饰。
- 庭院以层叠石灰门套、铜制玻璃灯笼、手绘陶瓷门牌、陶土与陶瓷花盆补充墙面层次。长椅配软坐垫、靠垫和垂下的条纹亚麻织物；橄榄树与三角梅使用相连枝干和成簇叶花，保留门洞与行走空间。远处点缀小型海边村落。
- 木帆船包含内外船壳、木板缝、肋骨、甲板、船桨、尾舵与索具。方帆沿船身横向桁杆展开，带亚麻纹理、缝线、鼓起与细褶；船身随同一套海浪起伏。船位兼顾桌面与手机窄屏视野。
- 海上有两座低矮、不对称的远岛、两组基部沉水的断岩礁石和少量滑翔海鸟。礁石带湿暗潮线与分层裂面，周围破浪泡沫随海面变化；船与礁石保持间距。
- 太阳使用明亮圆盘与柔和光晕。当前海景已移除太阳浮雕、海怪和漩涡，保留自然海岸的开阔感。

墙面、石材、织物及陶瓷图案使用本地程序素材；画作和橡木纹理由项目生成图片制作，随站点本地加载。素材说明见 [画作来源](public/art/README.md) 与 [橡木纹理来源](public/materials/README.md)。百叶、叶片等重复物件采用批量绘制，帆船小部件按材质合并，以控制场景开销。

## 换成自己的回忆

编辑 `src/content.ts` 中的 `chapters` 数组：

- `title`：章节标题，`date`：章节编号与名称，`subtitle`：英文小标题。
- `text`：短句，`note`：正文。字符串内的 `\n` 表示换行。
- `caption`：图下注释。
- `scene`：内置插画主题，支持 `coast`、`sunset`、`mountain`、`night`。
- 可选 `image`：照片路径。例如把照片放入 `public/memories/first.webp`，填写 `image: 'memories/first.webp'`。该相对路径同时适用于本地预览和 GitHub Pages 的 `/memory/` 子路径；加载失败时回退到插画。

照片路径直接交给浏览器解析，不会自动添加站点前缀，因此上述本地照片路径不要以 `/` 开头。建议使用宽度约 1200 像素的 WebP；照片默认按画框裁切。章节和页码按数组长度自动生成。修改内容或素材后，需要重新构建并发布。

- `tests/experience.spec.ts`：浏览器交互回归。

## 浏览器测试

本云环境已有 `/usr/bin/chromium`，不需要另行下载浏览器。

```sh
npm test
```

其他机器请修改 `playwright.config.ts` 的 `executablePath` 为已安装浏览器，或删除此项并通过 Playwright 安装 Chromium。当前共九项测试，覆盖：

- 桌面完整阅读流程、章节边界、声音与返回；手机滑动、布局和减少动态效果；无 WebGL 时直接阅读。
- 实际渲染相机的门洞通行、入室眼高、封面打开、纸页弯曲、返回原房间机位、花束落桌，以及海面连续画面的变化。开册过程中触发一次窗口调整，检查进度不倒退，并确认阅读页接管时镜头仍在移动，完成时遮罩和模糊度保持连续。
- 纱帘透明度、蕾丝镂空、顶部固定与下摆风动；家具尺寸、陈设支撑面和首次开场海景遮挡。
- 横帆方向与桁杆连接、岛礁基部沉水、船礁无重叠、篓子衬布不穿侧壁，以及手机船只可见性和画册点击区域。
- 真实浏览器中阅读页面的四个角与给定书页投影逐一对齐；退化投影可安全回退。无需 WebGL 的页面栅格测试检查文字、Canvas 插画和同源照片均有实际像素，画布可安全读取，并与实体书左右页纹理逐像素一致。
- 独立向过渡控制器逐帧输入移动中的书页投影，检查桌面与手机上两页各自的四角轨迹、实时重新定位、纵向落位，以及结束清理前后的几何位置、背景遮罩和模糊度一致；截图像素断言检查书页标记的实际绘制位置，覆盖布局坐标正确但画面偏移的问题。

截图保存在 `test-results/`，包括 `album-opening.png` 的实体翻页、`album-handoff.png` 的界面接续与 `album-reading.png` 的阅读终态。软件渲染测试用于检查功能与构图，真实手机帧率需要在目标设备验证。

云端 Chromium 使用 SwiftShader 软件渲染时，单帧可能超过一秒，因此开册完成、页面接续和返回房间的测试等待上限为 60 秒。此等待上限不改变场景动画时长，测试仍检查每一帧的进度与中间运动。
