# 默认唱片与上传音乐

默认唱片是用户提供的《Merry Christmas Mr. Lawrence》— 坂本龍一（Ryuichi Sakamoto）。这份 MP3 随网站提供给访客，源文件为 `src/assets/default-record.mp3`，约 5.0 MiB，构建时按内容生成文件名。

入室后点击桌上的唱片机或右上角唱片按钮开始播放；初次打开及刷新后保持暂停，不会自动播放。也可以不播放唱片，只听海浪。

## 在页面中选择

点击“更换音乐”可选择设备上的其他音频文件。选择后显示文件名并开始播放；点击唱片机可暂停或从原进度继续。界面会显示加载中、播放中、已暂停和失败状态。选过个人音乐后，唱片机说明中提供“恢复默认唱片”，会清除这首个人音乐的保存记录并播放默认曲目。

最近选择的一首个人音乐及其文件名保存在当前设备的当前浏览器中。“更换音乐”会替换保存的个人歌曲；刷新或下次打开页面后优先读取这首音乐，保持暂停，点击唱片机再开始播放，无需重新选择文件。个人选择的文件不上传到服务器，也不会成为网站的公共音乐，其他设备或浏览器不会自动同步。

没有保存的个人歌曲，或无法读取浏览器存储时，会使用默认唱片。清除网站数据会删除保存的个人音乐，下次打开时恢复默认唱片。无痕浏览、浏览器存储限制或空间不足也可能影响保存；保存失败时页面会提示，本次仍可播放所选文件。MP3、M4A、OGG、WAV、FLAC 等格式能否播放取决于浏览器支持，建议先使用 MP3 或 M4A。

阅读纪念册时音乐继续播放。切到后台会暂停，返回后再次点击唱片机继续；右上角静音同时控制音乐、海浪与猫咪声音。音乐播放时海浪会进一步轻下去。

个人音乐以 Blob 和文件名存入 IndexedDB，播放时创建本地地址；默认唱片直接使用网站中的音频资源，在首次点击播放时才赋予播放器音源，避免开场提前下载。音乐由一个原生音频播放器加载，使用 `preload="none"`，不预先把整首歌曲解码到房间音效的 AudioContext。快速连续点击、更换音源、切到后台或关闭页面时，旧的播放请求不会在稍后重新开始。
