# Sleeping tabby cat

`sleeping-tabby.glb` is an adaptation for this project. The surrounding tabletop and hanging original tail were removed. A shorter, curved and tapered tail was reconstructed using the photographed coat. Geometry was conservatively reduced, normals regenerated, and the photographic texture resized to 1024 × 1024 JPEG. The model was centered and normalized to a 46 cm horizontal span with its support at Y=0. It is a static scan; the application applies a subtle, grounded breathing deformation.

The result has 20,214 triangles, one mesh, one PBR material and one embedded texture, totaling 760,804 bytes. The adapted GLB also includes the attribution and modifications in `asset.extras`. Visible attribution is available from the room's “猫咪模型鸣谢” link to [the credits page](../credits.html).
