# 上传音乐

唱片机不预设曲目或演唱者，可以自由选择设备上的音频文件，播放自己喜欢的歌曲。

## 在页面中选择

入室后点击“上传音乐”、桌上的唱片机或右上角唱片按钮，选择音频文件。选择后显示文件名并开始播放；点击唱片机可暂停或从原进度继续。“更换音乐”可重新选择其他歌曲。

最近选择的一首音乐及其文件名保存在当前设备的当前浏览器中。“更换音乐”会替换保存的歌曲；刷新或下次打开页面后会读取已保存的音乐，保持暂停，点击唱片机再开始播放，无需重新选择文件。文件不上传到服务器，也不会成为网站的公共音乐，其他设备或浏览器不会自动同步。

清除网站数据会删除保存的音乐；无痕浏览、浏览器存储限制或空间不足也可能影响保存。保存失败时页面会提示，本次仍可播放所选文件。MP3、M4A、OGG、WAV、FLAC 等格式能否播放取决于浏览器支持，建议先使用 MP3 或 M4A。

阅读纪念册时音乐继续播放。切到后台会暂停，返回后再次点击唱片机继续；右上角静音同时控制音乐、海浪与猫咪声音。音乐播放时海浪会进一步轻下去。

音乐文件以 Blob 和文件名存入 IndexedDB，播放时创建本地地址。音乐由一个原生音频播放器加载，使用 `preload="none"`，不预先把整首歌曲解码到房间音效的 AudioContext。快速连续点击、更换音源、切到后台或关闭页面时，旧的播放请求不会在稍后重新开始。
