# 上传音乐

唱片机不预设曲目或演唱者，可以自由选择设备上的音频文件，播放自己喜欢的歌曲。

## 在页面中选择

入室后点击“上传音乐”、桌上的唱片机或右上角唱片按钮，选择音频文件。选择后显示文件名并开始播放；点击唱片机可暂停或从原进度继续。“更换音乐”可重新选择其他歌曲。

文件只为当前页面创建本地播放地址，不上传到服务器，也不会保存为网站的公共音乐。刷新页面后需重新选择。MP3、M4A、OGG、WAV、FLAC 等格式能否播放取决于浏览器支持，建议先使用 MP3 或 M4A。

阅读纪念册时音乐继续播放。切到后台会暂停，返回后再次点击唱片机继续；右上角静音同时控制音乐、海浪与猫咪声音。音乐播放时海浪会进一步轻下去。

音乐由一个原生音频播放器加载，使用 `preload="none"`，不预先把整首歌曲解码到房间音效的 AudioContext。快速连续点击、更换音源、切到后台或关闭页面时，旧的播放请求不会在稍后重新开始。
